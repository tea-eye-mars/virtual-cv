# Virtual CV - Portfolio Website

## 📌 Overview
This repository contains the source code, design assets, and documentation for my professional Virtual CV portfolio website. The platform serves as a dynamic digital showcase of my academic background, technical skills, and projects as an IT student specializing in Cybersecurity and Systems Analysis.

## 🚀 Sections Included
* **About Me:** Personal introduction, background, and career aspirations in ethical hacking and IT security.
* **Resume / CV:** Detailed breakdown of education, technical competencies, and academic achievements (such as programming distinctions).
* **Projects:** Showcase of technical projects, complete with descriptions and direct links to GitHub repositories.
* **Skills:** Categorized overview of programming languages, security tools, networking protocols, and systems analysis frameworks.
* **Contact Information:** Professional links and methods to get in touch.

## 🛠️ Web Technologies Used
* **HTML5 & CSS3:** Structured layout, responsive design, and CSS animations.
* **JavaScript:** Interactive UI components, mobile-friendly navigation toggle, and dynamic content rendering.
* **Hosting:** Deployed live via GitHub Pages.
